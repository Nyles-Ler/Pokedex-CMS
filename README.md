# Web Development 2 CMS Project
## Pokédex Content Management System

A full-stack Pokémon-themed Content Management System (CMS) developed for my Web Development 2 course. This project was built using PHP, MySQL, HTML, CSS, and JavaScript and focuses on database-driven web development, authentication systems, CRUD operations, and responsive front-end design.

---

# Features

- User authentication and login system
- Role-based access control
- Create, Read, Update, Delete (CRUD) functionality
- Dynamic Pokémon detail pages
- Search and filtering system
- Sorting functionality
- Image upload support
- Responsive front-end design
- Admin dashboard functionality
- Comment system for user interaction
- Database-driven content rendering

---

# Installation

## 1. Clone the repository

```bash
git clone https://github.com/Nyles-Ler/Web-Development-2-CMS-Project.git
```

## 2. Move the project into your XAMPP `htdocs` folder

Example:

```text
C:/xampp/htdocs/Web-Development-2-CMS-Project
```

---

## 3. Start Apache and MySQL

Open the XAMPP Control Panel and start:

- Apache
- MySQL

---

## 4. Import the database

1. Open phpMyAdmin
2. Create a new database
3. Import the provided `.sql` file into the database

---

## 5. Run the project

Open your browser and navigate to:

```text
http://localhost/Web-Development-2-CMS-Project
```
